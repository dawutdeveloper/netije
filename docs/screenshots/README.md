The supplied JPEG files are preserved without cropping, recompression, or interface changes.

## Updating the gallery

- Replace the corresponding image or add a descriptive filename and update the root README.
- Keep the primary gallery consistent in device size, language, and theme.
- Use fictional records for future populated screens and exclude personal information or notifications.
- Prefer PNG for future captures to keep interface text crisp; converting an existing JPEG to PNG does not recover detail.
- Keep meaningful alt text and captions, and link each thumbnail to its full-size asset.

Home and report screens with demo records would be useful additions when available.
